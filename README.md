> 猿猴道体配人心，心即猿猴意思深。  
> 大圣齐天非假论，官封弼马岂知音。  
>
> ——第七回

一盏灯，一方幕，一部西游。  
戏文皆出原书，一字不易；所易者，次第而已。  
旧事新读，古调今声。

## 五折

**第一折　入流**  
官封弼马心何足，名注齐天意未宁。　——第四回  
宴设蟠桃猴搅乱，安天大会胜蟠桃。　——第七回

**第二折　自己戴上**  
心猿归正，六贼无踪。　——第十四回

**第三折　白虎岭**  
扫地恐伤蝼蚁命，爱惜飞蛾纱罩灯。　——第二十七回

**第四折　都领回去了**  
外道施威欺正性，心猿获宝伏邪魔。　——第三十五回  
悟空大闹金兜洞，如来暗示主人公。　——第五十二回  
群魔欺本性，一体拜真如。　——第七十七回

**第五折　品级**  
猿熟马驯方脱壳，功成行满见真如。　——第九十八回  
九九数完魔灭尽，三三行满道归根。　——第九十九回  
径回东土，五圣成真。　——第一百回
